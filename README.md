# Project Dashboard AI – Issue Tracker

Welcome! 👋  
This repository exists **only** to collect and track issues, feature requests, and feedback for the **Project Dashboard AI** plugin —  
a productivity assistant compatible with **most JetBrains IDEs** (IntelliJ IDEA, PyCharm, WebStorm, PhpStorm, Rider, GoLand, etc.).

> ⚠️ Please note: the plugin source code is **not available** here.  
> This repository serves exclusively as a **public issue tracker**.

---

## 📌 How to report an issue
1. Go to the [Issues page](../../issues)
2. Click **New Issue**.
3. Choose the most relevant template (Bug Report, Feature Request, Question).
4. Fill in the details and submit.

---

## 💡 Tips for better reports
- Attach screenshots or error messages whenever possible.  
- Mention which **JetBrains IDE** you are using (e.g., PyCharm, WebStorm, Rider, etc.).  
- Be clear about steps to reproduce the issue.
